# Vue + vue-clip-track 开发的web在线剪辑工具

使用vue开发，后端生成视频使用python+ffmpeg实现。使用vue-clip-track组件实现时间轴，支持视频，音频，字幕，贴纸，滤镜，特效和转场的web在线剪辑工具。
src/webApi.py文件为后端生成视频接口和相应上传视频接口代码
src/AppTest.vue主界面入口程序
src\components\PropertyPanel.vue 组件属性面板代码
src\components\VideoPreview.vue 视频播放面板代码
